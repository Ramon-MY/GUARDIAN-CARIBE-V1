# Evidencias de Gestión de Configuración — GUARDIÁN CARIBE-V1

Esta carpeta está destinada a conservar las capturas de pantalla originales que demuestran el cumplimiento de la actividad. Las imágenes deben ser tomadas directamente desde GitHub, ser legibles y no estar recortadas de forma que oculten datos relevantes.

## Capturas requeridas

Guarde aquí los archivos con estos nombres sugeridos:

1. `01-repositorio-actualizado.png` — página principal del repositorio con nombre, rama, archivos y carpetas.
2. `02-readme-completo.png` — README mostrando objetivo, integrantes, estado inicial y organización del trabajo. Se pueden usar varias capturas si no cabe en una sola.
3. `03-estructura-carpetas.png` — vista de los directorios y documentos del repositorio.
4. `04-historial-commits.png` — historial que permita contar al menos tres commits distintos.
5. `05-requerimientos-redactados.png` — catálogo `documentacion/requerimientos.md` con los RF y sus prioridades.
6. `06-issues-creados.png` — listado de Issues RF-01 a RF-35.
7. `07-issue-detalle.png` — detalle de un Issue donde se vean historia de usuario, criterios de aceptación y prioridad.
8. `08-labels.png` — página Labels con las etiquetas de clasificación y prioridad.
9. `09-project-issues.png` — tablero GitHub Projects mostrando los Issues reales vinculados, sus títulos y los estados.

## Verificación antes de entregar

- [ ] El README contiene objetivo, integrantes reales, estado inicial y organización del trabajo.
- [ ] El repositorio contiene los documentos y la estructura solicitada.
- [ ] El historial muestra al menos tres commits.
- [ ] Existen 35 Issues, uno por cada requerimiento.
- [ ] Los Issues incluyen historia de usuario, criterios de aceptación y prioridad.
- [ ] Los Labels permiten identificar tipo y prioridad.
- [ ] Los 35 Issues originales están agregados al GitHub Project, sin duplicarlos como tarjetas independientes.
- [ ] El tablero muestra los elementos dentro de sus columnas.
- [ ] Las capturas están guardadas en esta carpeta y también incluidas en el documento final de entrega.

**Importante:** este archivo es una guía de organización. No sustituye las capturas reales; deben agregarse los archivos de imagen correspondientes.
