# GUARDIÁN CARIBE-V1

## Descripción del proyecto
GUARDIÁN CARIBE-V1 es una propuesta de plataforma ligera de monitoreo, detección y apoyo a la respuesta ante eventos y amenazas de ciberseguridad. Está orientada a entornos con recursos tecnológicos y conectividad limitados, con atención al contexto del Caribe y Latinoamérica.

## Objetivo del proyecto
Diseñar y desarrollar progresivamente una solución que permita registrar y consultar eventos de seguridad, identificar comportamientos sospechosos, gestionar alertas e incidentes y mantener trazabilidad de las acciones realizadas.

## Herramientas utilizadas y previstas
- Python 3.11 o superior.
- FastAPI para la API.
- SQLAlchemy para acceso a datos.
- Pydantic para validación.
- SQLite para el prototipo y PostgreSQL como alternativa.
- Pytest para pruebas automatizadas.
- Git y GitHub para control de versiones.
- GitHub Issues y GitHub Projects para gestión del trabajo.
